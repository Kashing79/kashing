### 五年测算要点（全部取自测算表）

- 年营业收入 **2,373,504 元**（五年不变）：路演厅 60.7% / 咖啡 33.4% / 茶室 6.0%
- 营业支出 **2,557,193 → 2,783,130 元**；人力占第一年支出 48.1%，年增 4.31%
- 税后利润 **-183,689 → -409,626 元**，五年累计 **-1,558,349 元**
- 经营现金流五年全负，五年末累计现金 **-1,544,348 元** → **回本周期不成立**（第 42 页如实说明）
- 第一年缺口 **183,689 元 = 收入需提高 7.74%**；唯一幅度现实的杠杆是路演厅月收入 120,000 → 135,307 元（+12.8%）
- 第 41 页三档情景（保守 / 基准 / 进取）**只调整两个已知总量口径**，不做任何假设性削减；只有进取档第一年转正

### 市场数据核实记录

- 莱坊《深圳甲级写字楼市场季度报告》2026 年第二季度原文核对：全市空置率 **22.7%**（环比 −0.6pp，连续两季改善）；
  福田中心区 **空置率 18.0%、平均净有效租金 168.3 元/㎡·月**，为八个子市场中最高；全市存量约 1,070 万㎡。三项均与原稿一致。
- 交叉核对发现口径分歧：仲量联行同期给出的全市空置率为 **24.9%**，戴德梁行给出的全市租金为 144.2 元/㎡·月。
  机构对「甲级」的篮子定义不同，数字不可混用。本版统一采用莱坊口径并在页面标注来源与时点。
- 需注意：莱坊 2025 年第四季度报告中，后海租金（173.3）曾略高于福田中心区（172.1），
  「福田中心区租金全市最高」在 **2026 Q2 成立**，更早时点不一定成立。
- **修正了原稿的一处张冠李戴**：「场租 50%、每届最高 100 万元」出自深圳市商务局《建设国际会展之都的若干措施》，
  并非「创投十九条」。第 29 页已拆成两条分别标注出处。
- 459,187 ㎡ 改标为「项目总建筑面积（含裙房商业）」并注明另有 460,665 ㎡ 一说；
  「≥60% 平安系占楼面」标注为 **待核实**。

## 汇报指南怎么用

- **逐页索引**在正文前，可直接对照 PPT 翻页；每页含：汇报重点、口语化话术、数据解释、页面衔接、建议时长、可能的追问与回答思路。
- 页码与 PPT **由同一份幻灯片注册表生成**（`build_deck.SLIDES`），指南里的交叉引用（「见第 N 页」）是符号引用，
  PPT 增删页后自动重编号，不会出现对不上的情况。
- 附录一：12 条高频追问的通用答法；附录二：8 处数据缺口的解释口径。
