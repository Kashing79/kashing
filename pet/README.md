# 球球 · 送给她的像素桌宠

一个住在 MacBook 屏幕最下面的小小世界：

- 一个**穿西装的像素小人**（你）
- 一只特别活泼的**小腊肠**
- 一只**大金毛**
- 一颗**小球**

小人会隔一阵子丢球给狗狗追，狗狗叼回来，小人摸摸它的头。
她累了可以只看着；想玩的时候，拖住小球甩出去就行。

完全离线：不联网、没有 API、不需要你在线、不需要任何系统权限。

## 怎么交给她

1. 把整个 `pet` 文件夹发给她（压缩成 zip 也可以）。
2. 她解压后，在这个文件夹里打开 Claude Code，说一句：**"帮我安装这个桌宠"**。
3. 她的 Claude Code 会读文件夹里的 `CLAUDE.md`，照着编译、安装、打开。

她的 Mac 需要：macOS 11 或更新版本，以及苹果免费的 Command Line Tools
（没有的话，她的 Claude Code 会带她装，点一下「安装」等几分钟）。

## 发给她之前，你可以先改这些

打开 `web/config.js`：

| 想改什么 | 改哪里 |
|---|---|
| 小人的头发、肤色、西装、领带颜色 | `person` |
| 小腊肠的毛色（红棕 / 黑棕 / 奶油） | `dachshund` |
| 让小人偶尔转过来挥手、说一句你写的话 | `messages`（默认是空的，不说话） |
| 多久自动丢一次球 | `autoPlaySeconds` |
| 夜里几点到几点睡觉 | `nightSleep` |

## 想先自己看看

用浏览器直接打开 `web/index.html`，就是一个可以玩的预览。
（预览有背景色；装到 Mac 上以后背景是透明的。）

## 她可以怎么玩

- 拖住小球甩出去：狗狗去追，叼回来给小人，小人再丢回去一次
- 点小人：他帮忙丢球
- 点小狗：摸摸它，冒一颗爱心
- 鼠标靠近小腊肠：它会蹦起来
- 夜里它们会睡觉，点一下就醒
- 菜单栏右上角的 🎾：调大小、开机自动启动、先躲起来、退出

## 文件夹里有什么

| 文件 | 作用 |
|---|---|
| `CLAUDE.md` | 给她的 Claude Code 看的安装说明 |
| `install.sh` / `uninstall.sh` | 安装 / 卸载 |
| `web/` | 像素画和玩法 |
| `src/main.swift` | Mac 外壳（透明置顶窗口） |
| `assets/` | App 图标 |
| `dev/` | 开发时用的测试脚本，安装用不到 |
