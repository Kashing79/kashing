# 球球 · 送给她的像素桌宠（第三版）

一个住在她 MacBook 桌面上的小小世界：

- 一个**穿西装的像素小人**（你）——会笑、会害羞、会看表、会整理领带，也会偷偷跳舞
- 一只特别活泼的**小腊肠**
- 一只温柔的**大金毛**
- 一颗**小网球**
- 屏幕最上面正中间的一颗**"灵动岛"**——它们的家
- 铺在**桌面上的一片像素草地**（在她的窗口和桌面图标后面）

它们从岛里跳出来，在**整个屏幕**上跑、玩球、互相闹；小人会**按时喂饭**，狗狗吃完会**找个角落拉粑粑**，
小人再拿袋子收拾干净；困了就回岛里睡觉。

完全离线：不联网、没有 API、不需要你在线、不需要任何系统权限。
第三版是**真正的 Mac 程序**（AppKit + Core Animation，玩法用系统自带的 JavaScriptCore 跑），不是网页。

## 怎么交给她（三种方法，挑一种）

**① 一行命令（最省事）**：让她打开「终端」，粘贴这一行，回车：

```bash
curl -fsSL https://raw.githubusercontent.com/Kashing79/kashing/main/pet/get.sh | bash
```

> 这一行要等这个分支合并进 `main` 以后才能用。合并之前用这一行（指定从这个分支下载）：
>
> ```bash
> curl -fsSL https://raw.githubusercontent.com/Kashing79/kashing/claude/busy-keller-0wb8et/pet/get.sh | QIUQIU_REF=claude/busy-keller-0wb8et bash
> ```
>
> 想开机自动出现，就在最后加上 ` -s -- --autostart`。

**② 发压缩包 + 她的 Claude Code**：把 `qiuqiu-pet.zip`（或整个 `pet` 文件夹）发给她（AirDrop、LINE、微信、邮件都行）。
她解压后在这个文件夹里打开 Claude Code，说一句：**"帮我安装这个桌宠"**。她的 Claude Code 会照着文件夹里的 `CLAUDE.md` 做。

**③ 自己装**：打开「终端」，输入 `bash `（后面有一个空格），把文件夹里的 `install.sh` 拖进终端窗口，按回车。

她的 Mac 需要：macOS 11 或更新版本，以及苹果免费的 Command Line Tools
（没有的话，安装时会提示她点一下「安装」，等几分钟）。

## 发给她之前，你可以先改这些

打开 `web/config.js`（每一项都有中文说明；不懂就交给 Claude Code，说"帮我改成……"）：

| 想改什么 | 改哪里 |
|---|---|
| 小人的头发、肤色、西装、衬衫、领带、皮鞋颜色 | `person` |
| 小腊肠的毛色（红棕 / 黑棕 / 奶油） | `dachshund` |
| 小人在小剧场里说的话（早安、晚安、欢迎回来……）；空着他就只用表情 | `lines` |
| 让小人隔一阵子转过来说一句你写的话 | `messages` |
| 岛上显示两地的时间（比如台北和你那边） | `clock`（再写 `hisClock` 告诉它哪个是你那边：你那边天亮 / 要睡时他会有反应） |
| 岛上显示"还有几天见面"，见面前一天和当天有特别的戏 | `reunion` |
| 生日、纪念日（那天金毛会把礼物叼到她鼠标旁边） | `dates` |
| 几点开饭、每天一块饼干、要不要拉粑粑 | `care` |
| 夜里几点到几点回岛睡觉 | `nightSleep` |
| 它们有多闹；上班时间只演安静的 | `liveliness`、`quietHours` |
| 有 9 段小剧场头几天先不演、第 1–4 天陆续出现（每天有点新东西）；不想等就关掉 | `discovery` |

## 想先自己看看

用浏览器直接打开 `web/index.html`，就是一个可以玩的预览（和 Mac 上用的是同一份玩法）。

## 她可以怎么玩

| 她做什么 | 会发生什么 |
|---|---|
| 拖住小球甩出去 | 狗狗去追、叼回来给小人，小人再丢 |
| 点小人 | 他丢球；点他的领带（歪了的时候）帮他正领带；按住他一会儿……（自己发现） |
| 点小狗 / 点鼻子 | 摸摸它 / 点鼻子它会打喷嚏 |
| 鼠标在狗狗身上来回蹭 | 挠到痒处，后腿直蹬，翻肚皮；另一只会挤过来吃醋 |
| 把鼠标停在坐着的金毛面前 | 它会抬爪子跟她击掌 |
| 鼠标慢慢在草地上移动 | 小腊肠会伏下身子悄悄跟踪，然后扑过去 |
| 快速晃几下鼠标 | 狗狗跑过来"找到啦"，然后跟着鼠标排队散步 |
| 按住拖走小人或小狗 | 拎起来；另外两个在下面跟着跑；放到金毛背上、放进小人怀里都有反应 |
| 把谁拎到顶上的岛上放开 | 大家回岛睡觉 |
| 鼠标移到岛上 | 岛会展开：丢球 / 摸摸 / 集合 / 喂饭 / 回岛睡觉（出来玩） |
| 点一下狗狗的饭碗或者地上的粑粑 | 帮忙收拾，小人会鞠躬谢谢她 |
| 离开电脑一会儿再回来 | 它们会迎接她，离开越久越热烈 |
| 菜单栏右上角的 🎾 | 丢球、开饭、回岛 / 出来、自动丢球、自动喂饭、拉粑粑开关、满屏幕跑、灵动岛、桌面草地（整个桌面 / 底部一条 / 不要）、大小、开机自动启动、先躲起来、退出 |

除了小人、小狗、小球、岛和偶尔可以点的小东西，其他地方鼠标会直接穿过去，不挡她用电脑。

## 它们自己会做的事

一共 180 多段小剧本和小动作（完整的列表在 [`SCENES.md`](SCENES.md)），按时间、她在不在、谁累了来挑，不会老是重复：

- **狗狗和狗狗**：金毛趴下来让小腊肠赢、故意输掉拔河、钻到金毛肚子底下、抢暖窝、两只一起抬一根树枝、
  趁金毛打盹偷玩具、给金毛舔耳朵、小狗做梦在跑金毛伸爪按住、走散了跑回来转圈重逢……
- **小人和狗狗**：金毛靠过来差点把他挤倒、教坐下（一个全做了，一个就是不坐）、颠球、猜零食在哪只手、
  抱小腊肠像抱法棍、三十公斤的"小狗"要坐他腿上然后被睡住了、梳毛梳得一身狗毛、捉迷藏、午睡叠成一堆、
  没人看的时候偷偷跳舞被发现、从口袋里掏出一张照片看……
- **时间和日子**：早上出岛巡视、整点看表、下午茶、一起看夕阳、睡前哈欠会传染、睡前故事、
  五点二十的一颗小爱心、周末野餐、撕日历倒数见面、见面那天……
- **地方**：岛是玩具箱（敲一敲掉出玩具）、程序坞当沙发、程序坞后面露出潜望镜一样的尾巴、
  把饼干埋在屏幕角落改天再挖、睡过的地方第二天开小花……
- **喂饭和拉粑粑**：到点小人端着碗、倒狗粮、喊"等一下"再放行；吃完喝水；过一会儿狗狗转圈找地方、
  蹲一下、蹬两下草；小人叹口气、套袋捡走、丢进垃圾桶。全程可爱、不恶心，只在屏幕左下角或右下角，
  一分钟内一定收拾干净，不会出现在她鼠标旁边。偶尔有一次"狗屎运"（金色的，配四叶草）。
- **各自的小动作**：小人看表、正领带、拉袖口、看手机笑、抛接球、指尖转球、系鞋带、吹口哨、比心……；
  狗狗甩毛、伸懒腰、歪头、立起来瞭望、青蛙趴、咬小飞虫、晒太阳、四脚朝天睡……

## 文件夹里有什么

| 文件 | 作用 |
|---|---|
| `CLAUDE.md` | 给她的 Claude Code 看的安装说明 |
| `get.sh` | 一行命令安装用的脚本（从 GitHub 下载这个文件夹，再运行 install.sh） |
| `install.sh` / `uninstall.sh` | 安装 / 卸载 |
| `web/config.js` | 可以改的设定 |
| `web/dogs.js` | 两只狗：一副会动的骨架，每一帧现画成像素（真实的步态、34 个姿势） |
| `web/person.js` | 穿西装的小人：骨架、19 种表情、59 个姿势、40 个小动作 |
| `web/fx.js` | 小球、碗、袋子、表情符号这些小东西（210 张小图） |
| `web/lawn.js` | 草地（白天 / 傍晚 / 夜里三套颜色） |
| `web/pet.js` | 玩法引擎：跑、丢球、导演、照料 |
| `web/needs.js` | 什么时候饿、什么时候要上厕所 |
| `web/scenes/` | 一段一段的小剧本（想加新的，照着 `pet.js` 开头"怎么写一场戏"写） |
| `web/index.html`、`web/web.js`、`web/island.js` | 浏览器预览和手机网页版用的 |
| `src/*.swift` | Mac 程序：透明窗口、桌面草地、灵动岛、菜单、鼠标穿透 |
| `iphone/`、`phone/` | iPhone 主画面小组件 / 网页 App |
| `dev/` | 开发时用的测试脚本，安装用不到 |

## 验证过 / 没验证过

- **验证过**（GitHub 的云端 Mac 虚拟机，macOS 15、26、27）：只用 Command Line Tools 编译、从带隔离标记的文件安装、
  一行命令安装、只开一个、卸载干净、自检（宠物真的画出来、背景透明）、岛在菜单栏上面、草地在壁纸上面桌面图标下面、
  模拟鼠标点击和拖球。玩法本身在这台开发机上做过长时间的快进模拟（各种乱点乱拖、睡眠唤醒、改时间）。
- **没验证过**：带刘海的真 MacBook 屏幕、真机上的耗电、Intel 的 Mac、外接多个屏幕、真正重启后的开机自动启动、真 iPhone。
