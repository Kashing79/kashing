# 球球 · 送给她的像素桌宠

一个住在她 MacBook 屏幕上的小小世界：

- 一个**穿西装的像素小人**（你）
- 一只特别活泼的**小腊肠**
- 一只**大金毛**
- 一颗**小球**
- 屏幕最上面正中间的一颗**"灵动岛"**——它们的家

它们从岛里跳出来，在**整个屏幕**上到处跑、玩球、互相闹；困了就回岛里睡觉。
完全离线：不联网、没有 API、不需要你在线、不需要任何系统权限。

## 怎么交给她

1. 把 `qiuqiu-pet.zip`（或整个 `pet` 文件夹）发给她：AirDrop、LINE、微信、邮件都行。
2. 她解压后，在这个文件夹里打开 Claude Code，说一句：**"帮我安装这个桌宠"**。
3. 她的 Claude Code 会读文件夹里的 `CLAUDE.md`，照着编译、安装、打开。

不用 Claude Code 也可以：打开「终端」，输入 `bash `（后面有一个空格），
把文件夹里的 `install.sh` 拖进终端窗口，按回车。

她的 Mac 需要：macOS 11 或更新版本，以及苹果免费的 Command Line Tools
（没有的话，安装时会提示她点一下「安装」，等几分钟）。

## 发给她之前，你可以先改这些

打开 `web/config.js`：

| 想改什么 | 改哪里 |
|---|---|
| 小人的头发、肤色、西装、领带颜色 | `person` |
| 小腊肠的毛色（红棕 / 黑棕 / 奶油） | `dachshund` |
| 让小人偶尔转过来挥手、说一句你写的话 | `messages`（默认是空的，不说话） |
| 多久自动丢一次球 | `autoPlaySeconds` |
| 夜里几点到几点回岛睡觉 | `nightSleep` |
| 岛上显示两地的时间（比如台北和你那边） | `clock` |
| 岛上显示"还有几天见面" | `reunion` |

## 想先自己看看

用浏览器直接打开 `web/index.html`，就是一个可以玩的预览。
（预览有背景色；装到 Mac 上以后背景是透明的，它们直接在她的桌面和窗口上面跑。）

## 她可以怎么玩

| 她做什么 | 会发生什么 |
|---|---|
| 拖住小球甩出去 | 狗狗去追、叼回来给小人，小人再丢回去一次 |
| 点小人 | 他帮忙丢球 |
| 点小狗 | 摸摸它，冒一颗爱心 |
| 按住小人或小狗拖走 | 把它拎起来，放到屏幕别的地方 |
| 把它拎到顶上的岛上放开 | 送大家回岛睡觉 |
| 鼠标靠近小腊肠 | 它会蹦起来 |
| 鼠标移到顶上的岛 | 岛会展开：丢球 / 摸摸 / 集合 / 回岛睡觉（出来玩） |
| 菜单栏右上角的 🎾 | 大小、只在屏幕底部活动、关掉岛、开机自动启动、先躲起来、退出 |

除了小人、小狗、小球和岛，其他地方鼠标会直接穿过去，不挡她用电脑。

## 它们自己会做的事

**丢球**：小人丢球 → 两只狗抢着追 → 小腊肠会跳起来接 → 有时两只咬住同一颗球拔河
→ 叼回来交给小人 → 小人摸头（对小腊肠会蹲下来）。小人偶尔做个假动作，小腊肠冲出去才发现被骗了。
金毛跑累了会趴着喘气，只看不追。

**狗狗和狗狗**：互相闻一闻再邀玩 · 你追我赶（跑一半换过来追）· 挤在一起睡觉 ·
小腊肠跳到金毛背上坐着 · 金毛给小腊肠舔毛，小腊肠翻肚皮。

**小人和狗狗**：蹲下来揉小腊肠的肚子，金毛也凑过来要 · 跟金毛握手 · 发零食（小腊肠站起来接）·
三个一起坐着发呆 · 带着两只狗排队散步 · 金毛来讨摸，小腊肠吃醋蹦蹦跳。

**各自的小动作**：小腊肠满场疯跑、追自己的尾巴、刨地、打滚、追蝴蝶；
金毛趴着晒太阳、挠痒、慢慢巡逻；小人整理领带、看手表、伸懒腰、转过来挥手。

## 她的 iPhone

iPhone 上做不了悬浮桌宠，改用「加到主画面的网页 App」加「主画面小组件」。
做法见 [`iphone/README.md`](iphone/README.md)。

## 文件夹里有什么

| 文件 | 作用 |
|---|---|
| `CLAUDE.md` | 给她的 Claude Code 看的安装说明 |
| `install.sh` / `uninstall.sh` | 安装 / 卸载 |
| `web/config.js` | 可以改的设定 |
| `web/dogs.js` | 两只狗是怎么画出来的（有骨架、会动的像素狗） |
| `web/pet.js` | 玩法和所有的互动 |
| `web/island.js` | 顶上的岛 |
| `web/sprites.js` | 小人、小球、爱心这些像素画 |
| `src/main.swift` | Mac 外壳（铺满屏幕的透明窗口，鼠标可以穿过去） |
| `assets/` | App 图标 |
| `iphone/` | iPhone 主画面小组件和说明 |
| `phone/` | 生成 iPhone 网页 App 的脚本（成品在仓库根目录的 `docs/qiuqiu/`） |
| `dev/` | 开发时用的测试脚本，安装用不到 |
