# 球球 · iPhone 版

iPhone 不允许任何 App 悬浮在别的 App 上面，所以手机上没有"真悬浮"的桌宠。
这里用两样免费、不需要开发者账号的东西来代替：

| | 是什么 | 她看到的 |
|---|---|---|
| **网页 App** | 加到主画面的一个图标，点开全屏 | 和 Mac 上一样能玩：拖球、点小人丢球、点小狗摸摸。加好后没有网络也能打开 |
| **主画面小组件** | 用免费 App「Scriptable」显示的一块小画面 | 不用打开任何东西，主画面上一直能看到小人和狗狗。约每 15 分钟换一个姿势，夜里睡觉。点一下打开网页 App |

## 一、网页 App

### 你要先做一次：把网页放上网

这个仓库是公开的，可以用 GitHub 免费的 Pages 功能当网址：

1. 打开仓库 → **Settings** → 左边 **Pages**。
2. **Source** 选 **Deploy from a branch**。
3. **Branch** 选放着 `docs` 文件夹的那个分支（合并之后选 `main`），文件夹选 **/docs**，点 **Save**。
4. 等几分钟，网址是：`https://kashing79.github.io/kashing/qiuqiu/`

### 她在 iPhone 上

1. 用 **Safari** 打开上面的网址。
2. 点下方的**分享**按钮 → **加入主画面**。
3. 以后点主画面上的「球球」图标就行。

页面会按她手机的语言显示繁体或简体；白天、傍晚、夜里天空颜色不同。

## 二、主画面小组件

1. 在 App Store 安装 **Scriptable**（免费）。
2. 把 `qiuqiu-widget.js` 发到她手机上（AirDrop、讯息、邮件都行），全选复制里面的内容。
3. 打开 Scriptable → 右上角 **+** → 贴上 → 把名字改成「球球」。
4. 回到主画面，长按空白处 → 左上角 **+** → 找 **Scriptable** → 选**中**尺寸（或小尺寸）→ 加入。
5. 长按这个小组件 → **编辑小组件** → **Script** 选「球球」。

## 改了东西以后

像素画和颜色都来自 `pet/web/`。改完之后重新生成这两样：

```bash
python3 pet/phone/build.py      # 生成 docs/qiuqiu/（网页 App）
node pet/iphone/build.js        # 生成 pet/iphone/qiuqiu-widget.js（小组件）
```

## 目前的验证情况

- 网页 App：在电脑上用 iPhone 14 尺寸模拟过（直、横两个方向，手指拖球），没有报错。**没有在真 iPhone 上试过。**
- 小组件：脚本逻辑用假的 Scriptable 接口跑过并看过画出来的图。它只用了别人已经在用的那几个接口，但**没有在真 iPhone 上试过**。
- 小组件多久刷新一次由 iOS 决定，脚本只能"建议"15 分钟；它不会动。
